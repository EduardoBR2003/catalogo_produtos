# Catálogo de Produtos

Atividade 5 – Lista.

Aplicativo Flutter que mostra uma lista de produtos (nome, preço e categoria) em Cards, com ícone de acordo com a categoria e botão Comprar. Pelo botão flutuante é possível cadastrar um novo produto, escolhendo a categoria em um DropdownButton; ao confirmar, o produto é incluído no catálogo. Ao tocar em um produto aparece um SnackBar avisando que ele foi adicionado ao carrinho.

## Como executar

```bash
flutter pub get
flutter run
```
